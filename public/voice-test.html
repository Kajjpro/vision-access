mn-MN recognition test

Open this on the target Android phone in Chrome and press the button. It reports whether Chrome's speech engine accepts Mongolian. Needs a network connection — recognition is server-side.

It also measures the two things the app's accuracy now depends on: how many alternatives the engine returns for a Mongolian place name, and how long each phase takes on this phone. If mn-MN comes back with only one alternative, searching them all buys nothing and MAX_ALTERNATIVES is dead weight.
